# Common Failures and What They Mean

| Symptom | Likely cause                                                                                                                                                                   | Fix                                                                                                                                                                                                                                           |
|---|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `Could not find or load main class …` | Module never compiled, or `classes_gen` stale                                                                                                                                  | `MAKE` the module with `rebuild: true` (see `references/compile-before-run.md`)                                                                                                                                                                          |
| `Concept '<X>' is not runnable through this tool: the root must implement IMainClass or ITestCase, or be a ClassConcept whose getMainMethod() resolves a static main(<String[]-subtype>) method (visibility is not checked)` | Root matches none of the three accepted shapes — typically a `ClassConcept` without a `main`, or a domain-specific root whose language never declared `IMainClass`/`ITestCase` | Either give the class a qualifying `main`, target a different root, or extend the language to implement `IMainClass`                                                                                                                          |
| `Module '<moduleName>' (owner of node '<nodeName>') has compileInMPS=false; …` | Owning module's Java facet is set to JPS-compile (or `None`); the producer (and this tool) refuse because `classes_gen` will be empty at launch                                | Default: take the IDEA-MCP file-path fallback in `references/classconcept-and-fallbacks.md`. Only flip the JavaModuleFacet to `Compile.MPS` after confirming with the user — `None` is often intentional (sandbox / externally-built / packaged modules) |
| Tool succeeds but the new config "replaces" an existing one silently | Same effective name and type collide on `<typeId>.<name>`                                                                                                                      | Pass a distinct `configurationName`. Two snapshots that start with the same root share `<first>,...` unless you name them |
| `'<ref>' is a model; pass it in modelReference` | A model reference was sent as `nodeReference` | Retry with `modelReference`. One model alone is live; combined with other targets it is a snapshot |
| `No tests found in model` | The model has no root `tryToWrap` accepts. An empty `NodesTestCase` does not count | Add an uncommented test method, or pass a different model |
| `Cannot mix legacy (compatibility-mode) and modern tests` | One config would drop a group at launch | Give the named legacy tests a configuration of their own |
| `<N> entries failed:` followed by `<parameter>[<index>]: <sentence>` lines | Several entries of one call were rejected; nothing was created. Lines run `nodeReference` entries, then `modelReference` entries, then call-wide checks; a scalar parameter has no index | Fix every listed entry, then retry once |
| `Root '<name>' is not a test; a Java Application config runs one main` | A main class or other non-test root was listed with other targets | Drop it from the list, or give it a call of its own |
| `Test case '<name>' has no test methods` | A test case listed with other targets has no uncommented test method, so discovery skips it | Add a test method, or leave the root out |
| `Model '<name>' is read-only` | A library or stub model; the IDE does not create run configurations for those | Pass a project model |
| `Module '<name>' must be compiled by MPS (compileInMPS=false). Can't run tests.` (or `Modules '<a>' and '<b>' …`) | A model, or a root among several targets, lives in a module MPS does not compile. A single test root is not gated | Same choice as for the Java Application gate above; confirm before flipping the facet |
| MPS MCP `execute_run_configuration` rejects `filePath`+`line` under `source_gen` | The MPS variant doesn't synthesize file-level launchers there                                                                                                                  | Use the IDEA MCP variant — same arguments, broader file-level support                                                                                                                                                                         |
| Empty `output`, `exitCode: 0` | Script ran but wrote nothing to stdout (Kaja-style GUI, file output, etc.)                                                                                                     | Inspect side channels; success is real                                                                                                                                                                                                        |
| The run configuration failed to execute due to a ClassNotFoundException | You are attempting to use IDEA's mcp tools instead of the ones provided by MPS for run configurations - `get_run_configurations`, `execute_run_configuration`                                             | Use MPS MCP                                                                                                                                                                                                                                   |
